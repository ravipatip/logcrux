# Security Policy

## Supported Versions

Only the latest released version of logcrux is supported with security fixes.

## Reporting a Vulnerability

Please report security vulnerabilities privately via
[GitHub Security Advisories](https://github.com/ravipatip/logcrux/security/advisories/new)
rather than filing a public issue.

logcrux runs entirely locally (no network calls, no telemetry), so most
relevant reports concern input handling — e.g. a malformed or adversarial log
file causing a crash, hang, or resource exhaustion. Include a sample input
and the command line used, if possible.

There is no bug bounty program. Reports will be acknowledged and addressed
on a best-effort basis.
